# P0.1 — Auction Feel

## Goal

Membuktikan satu hal: **membaca NPC + memutuskan BID/STOP + reveal barang terasa menyenangkan.**

Prototype ini sengaja kecil dan tidak mewakili kualitas visual final.

## Flow

1. Lot 01 — Rice cooker
   - Bu Ratna adalah end user.
   - Pelajaran: nilai guna pribadi dapat mengalahkan margin reseller.
2. Lot 02 — Kotak campuran
   - Jaka menawar sampai batas reseller.
   - Pelajaran: kemenangan kecil tetap kemenangan.
3. Lot 03 — Kamera analog
   - Investigasi Body / Lensa / Tas.
   - Jaka masuk bluff mode.
   - STOP: Jaka terjebak membeli.
   - BID melewati bluff threshold: MC menang.
4. Reveal
   - Body biasa.
   - Lensa produksi terbatas.
   - Estimasi kolektor Rp2,8–3,6 juta.

## Prototype NPC

### Bu Ratna
- role: end user
- aggression: low
- Lot 01 max: Rp130.000
- Lot 03 max: Rp100.000

### Jaka
- role: reseller + ego
- aggression: medium
- Lot 02 max: Rp90.000
- Lot 03: bluff
- counter bid: MC + Rp30.000
- bluff threshold: Rp230.000

## P0.1 Success Criteria

- Pemain membaca bahwa Jaka menawar MC, bukan kameranya.
- STOP/BID menghasilkan emosi, bukan respons netral.
- Bid Rp200k–260k terasa tegang.
- Reveal memberi payoff.
- Pemain ingin mencoba cabang lain.
